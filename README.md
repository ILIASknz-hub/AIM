# Aïn Souk — application Android (prototype)

Application hors ligne de l'auxiliaire d'autorité : relevé des prix et alerte de spéculation, abattage clandestin, produits périmés, réclamations — Province de Sidi Kacem.

L'APK est fabriqué automatiquement par GitHub Actions (onglet **Actions** → dernière exécution → **Artifacts** → `AinSouk-apk`).

Prototype réalisé dans le cadre du mémoire de fin d'études — Institut Royal de l'Administration Territoriale.
